      Receipt printer

      Choose your thermal receipt printer and receipts print straight to it as you finish a sale — no dialog. The receipt is sent to the printer directly rather than through its Windows driver, so this works with printers whose driver can't drive them (USB-to-parallel cables are the usual culprit). Choose “Ask me each time” to go back to the normal print dialog.

      Day report by email

      The Till can email a PDF of the day's takings to one address — useful on days you cannot be in the shop. Sending goes through your own Gmail account, so nothing passes through anyone else's server.

      Your ordinary Google password will not work here — Google refuses it. Gmail needs a 16-character App Password: open myaccount.google.com/apppasswords (turn on 2-step verification first if it asks), create one called “Lyra PoS”, and paste the 16 letters below. Spaces do not matter.

      Categories

      Add a category below. Remove one with the ✕ — if products are filed under it you'll be asked which category they should move to.

      Backup

      All data lives only on this computer. Export a backup file regularly, especially before reinstalling.

      Import products

      Bring in a product list exported from POS Maid (Excel/CSV) or any spreadsheet with Name, SKU/barcode, price, and stock columns. Matches existing products by SKU and updates them; anything new is added.

      Security

      The Admin Key protects Stock, Ledger, Overview, and Setup from Client mode. Anyone at the till can still ring up sales without it.

      Danger zone

      These can't be undone. Both require your Admin Key again to confirm, even though you're already unlocked.

      Reset sales & stock
      Clears the Ledger, Overview history, and held sales, and sets every product's stock to 0. Products, prices, categories, and settings are kept.
      Reset all data
      Wipes everything back to a blank install — products, sales, categories, settings, and the Admin Key itself. You'll set a new Admin Key right after.
