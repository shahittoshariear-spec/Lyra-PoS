      Backup

      All data lives only on this computer. Export a backup file regularly, especially before reinstalling.

      Import products

      Bring in a product list exported from POS Maid (Excel/CSV) or any spreadsheet with Name, SKU/barcode, price, and stock columns. Matches existing products by SKU and updates them; anything new is added.

      Security

      The Admin Key protects Stock, Ledger, Overview, and Setup from Client mode. Anyone at the till can still ring up sales without it.

      Danger zone

      These can't be undone. Both require your Admin Key again to confirm, even though you're already unlocked.

      Reset sales & stock
      Clears the Ledger, Overview history, and held sales, and sets every product's stock to 0. Products, prices, categories, and settings are kept.
      Reset all data
      Wipes everything back to a blank install — products, sales, categories, settings, and the Admin Key itself. You'll set a new Admin Key right after.
